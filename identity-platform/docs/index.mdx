Identity Platform Cloud is WSO2's identity and access management as a service. Each product's Cloud documentation is one part of it.

## Products

### Identity Server

Single sign-on, multi-factor authentication, API authorization and user management for your apps.

- [Identity Server Cloud](docs:identity-server/cloud/)
