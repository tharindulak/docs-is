This section explains how owners can create multiple organizations in the {edition.productName} Console, switch between them, manage user attributes, perform account recovery, provide users with self-service capabilities, and mitigate risks via configuring security measures for user accounts.

- Organization owners can manage the resources within their organizations.

    See [Manage multiple organizations](../organization-management/manage-organizations.mdx) for instructions.

- User attributes represent a user's information within an organization. These default attributes can either be mapped to OpenID Connect claims or SCIM 2 attributes.

    See [Manage user attributes](../users/attributes/index.mdx) for instructions.

- In {edition.productName}, accounts can be recovered by administrators or by the users themselves. Users can recover their forgotten passwords using the self-service passwords recovery option.

    See [Configure password recovery](../account-configurations/account-recovery/password-recovery.mdx) for instructions.

- Users can self-register to an organization in {edition.productName} via an application's login page.

    See [Configure self-registration](./configure-self-registration.mdx) for instructions.

- When you onboard several users onto your organization, it is of utmost importance to secure their accounts from unauthorized logins or other unfavorable misuses. Some popularly effective methods include locking the account on consecutive failed login attempts and using reCAPTCHA to detect bots.

  See the following sections for instructions on configuring these security measures:

  - [Configure login-attempts security](./account-security/login-attempts-security.mdx)
  - [Configure bot detection](./account-security/bot-detection.mdx)
