You can now configure alternative login identifiers so that the users of your WSO2 Identity Platform organization have the capability to use these identifiers to log in.

:::note
The primary login identifier is the attribute you configure as your username. Learn more about [configuring username validation](../../user-accounts/account-login/username-validation.mdx).
:::

WSO2 Identity Platform allows admins to assign the following attributes as alternative login identifiers of the organization:

- `Email`
- `Mobile`

To configure alternative login identifiers for your organization:

1. On the WSO2 Identity Platform Console, go to **Login & Registration**.

2. Under **Login Identifier**, click on **Alternative Login Identifier**.

3. Select `Email` and/or `Mobile` as alternative login identifiers.

    <img src={require("../../../../assets/cloud/img/guides/organization/account-login/configure-alternate-login-identifiers.png").default} alt="Configure alternative login identifiers" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    :::note
    - Ensure that every user within your organization has a unique value assigned to the chosen login identifiers. For new users, WSO2 Identity Platform will ensure it's uniqueness.

    - If you have chosen `Email` as the [username type](../../user-accounts/account-login/username-validation.mdx), it automatically becomes the primary login identifier. Therefore, configuring it as an alternative login identifier will be disabled.
    :::

4. Click **Update** to save the changes.

    :::note
    A consent prompt will appear if [uniqueness validation](../../users/attributes/configure-unique-attributes.mdx) is not already configured for the selected attribute(s). Without confirmation, the alternative login identifier configuration will not be applied.
    :::

Upon successful configuration, the login and recovery user interfaces will update according to the defined login identifier attributes.
