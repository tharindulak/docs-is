Information directly related to users in an organization, such as username, email, address, etc., is stored as user attributes in {edition.productName}. You can view the attributes, update them, and decide if and how they should appear in a user's profile. Learn more about [managing attributes in your organization](./user-attributes/manage-attributes.mdx).

You can also map your [OpenID Connect attributes](./manage-oidc-attribute-mappings.mdx) or [SCIM2 attributes](./manage-scim2-attribute-mappings.mdx) to user attributes in your organization.
