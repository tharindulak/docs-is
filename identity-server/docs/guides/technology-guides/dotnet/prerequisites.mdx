Before you start, ensure you have the following:

<Variants>

<Edition only="cloud">

- About 60 minutes of time.
- A WSO2 Identity Platform account.
- Create [a test user in WSO2 Identity Platform](../../users/users/manage-users.mdx#onboard-users)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) or later.
- [Visual Studio Code](https://code.visualstudio.com/).

</Edition>

<Edition only="self-hosted">

- About 60 minutes of time.
- Create [a test user in Identity Server](../../users/users/manage-users.mdx#onboard-users)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) or later.
- [Visual Studio Code](https://code.visualstudio.com/).

</Edition>

</Variants>
