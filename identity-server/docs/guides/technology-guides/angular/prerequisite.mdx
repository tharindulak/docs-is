## Before you start, ensure you have the following

<Variants>

<Edition only="cloud">

* About 60 minutes
* WSO2 Identity Platform [account](../../../get-started/create-identity-platform-account.mdx)
* [Node.js](https://nodejs.org/en/download/package-manager) v18+ and npm
* Install [Angular CLI](https://nodejs.org/en/download/package-manager)
* A favorite text editor or IDE

</Edition>

<Edition only="self-hosted">

* About 60 minutes
* WSO2 Identity Server [setup](https://is.docs.wso2.com/en/latest/get-started/quick-set-up/)
* [Node.js](https://nodejs.org/en/download/package-manager) v20+ and npm
* Install [Angular CLI](https://nodejs.org/en/download/package-manager)
* A favorite text editor or IDE

</Edition>

</Variants>

:::note
You need to have installed [Node.js](https://nodejs.org/en/download/package-manager) v18+ and npm (which comes inbuilt with Node) to run this sample. Although Node.js is primarily a server-side language,it needs to have been installed to manage dependencies and run scripts for our project.
:::
