First unless you already have done that, you need to create an organization in {edition.productName} and register your application as a single page application.

<Variants>

<Edition only="cloud">

* Sign up for a [free WSO2 Identity Platform account](../../../get-started/create-identity-platform-account.mdx)

</Edition>

<Edition only="self-hosted">

* Download and [setup WSO2 Identity Server](https://is.docs.wso2.com/en/latest/get-started/quick-set-up/) 

</Edition>

</Variants>

* Sign into {edition.productName} console and navigate to **Applications > New Application.**
* Select **Single Page Application**

<img src={require("../../../../assets/img/complete-guides/angular/image8.png").default} alt="Select Single Page Application" width="600" style={{display: "block", margin: "0"}} />  

Next, complete the wizard popup by providing a suitable name and an authorized redirect URL.

<Variants>

<Edition only="cloud">

:::note[Example]
name: asgardeo-angular

Authorized redirect URL: http://localhost:4200
:::

</Edition>

<Edition only="self-hosted">

:::note[Example]
name: is-angular

Authorized redirect URL: http://localhost:4200
:::

</Edition>

</Variants>

<img src={require("../../../../assets/img/complete-guides/angular/image5.png").default} alt="Register a new application" width="600" style={{display: "block", margin: "0"}} />

:::info
The authorized redirect URL determines where {edition.productName} should send users after they successfully log in. Typically, this will be the web address where your app is hosted. For this guide, we'll use [http://localhost:4200](http://localhost:4200), as the sample app will be accessible at this URL.
:::

Make a note of the following values from the **Protocol** and **Info** tabs of the registered application. You will need them to configure the authentication SDK

* **`client-id`** from the **Protocol** tab.
* **`issuer`** from the **Info** tab.

In this step, we have ve registered our Angular app as an application in the {edition.productName} console and generated the required metadata. Next, we will create a Angular app.
