First unless you already have done that, you need to create an organization in {edition.productName} and register your application as a single page application.

<Variants>

<Edition only="cloud">

* Sign up for a [free {edition.productName} account](../../../get-started/create-identity-platform-account.mdx)

</Edition>

<Edition only="self-hosted">

* Download and [setup WSO2 Identity Server](https://is.docs.wso2.com/en/latest/get-started/quick-set-up/)

</Edition>

</Variants>

* Sign into {edition.productName} console and navigate to **Applications > New Application.**
* Select **Single Page Application.**

<img src={require("../../../../assets/img/complete-guides/javascript/image5.png").default} alt="Select Single Page Application" width="600" style={{display: "block", margin: "0"}} />  

Next, complete the wizard popup by providing a suitable name and an authorized redirect URL.

:::note[Example]
name: wso2-javascript

Authorized redirect URL: http://localhost:5173
:::

<img src={require("../../../../assets/img/complete-guides/javascript/image8.png").default} alt="Register a new application" width="600" style={{display: "block", margin: "0"}} />

:::info
The authorized redirect URL determines where {edition.productName} should send users after they successfully log in. Typically, this will be the web address where your app is hosted. For this guide, we'll use [http://localhost:5173](http://localhost:5173), as the sample app will be accessible at this URL.
:::

Note down the following values from the **Protocol** tab of the registered application. You will need them to configure  WSO2 Identity Platform JavaScript SDK.

* **`client-id`** from the **Protocol** tab.

In this step, we have registered our JavaScript app as an application in the {edition.productName} console and generated the required metadata. Next, we will create a JavaScript app using Vite.
