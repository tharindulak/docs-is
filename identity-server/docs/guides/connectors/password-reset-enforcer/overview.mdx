Password Reset Enforcer lets you enforce password reset upon expiration as part of an application's authentication flow. When a user signs in with an expired password, {edition.productName} redirects the user to the password reset screen before completing authentication.

You can use this connector to:

- Ensure users update passwords on a defined schedule.
- Block access to an application until the user resets an expired password.
- Apply your organization’s password validation rules during password reset.

Configure password expiration rules from the {edition.productName} Console. For instructions, see [Password validation](../../account-configurations/login-security/password-validation.mdx).

![Password Reset Enforcer overview](../../../../assets/self-hosted/img/connectors/password-reset-enforcer/password-reset-enforcer-overview.png)

How it works,

- A user starts a sign-in flow to your application.
- {edition.productName} evaluates password expiration based on your configured password expiration rules.
- If the password has expired, {edition.productName} shows the password reset screen.
- After the user resets the password successfully, {edition.productName} continues the authentication flow.
