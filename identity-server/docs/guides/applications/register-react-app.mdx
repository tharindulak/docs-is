{edition.productName} provides an application template with default configurations to register a React application with minimal effort.

To register a React application,  

1. On the {edition.productName} Console, go to **Applications**.

2. Click **New Application** and select **React**.

    <img src={require("../../../assets/img/guides/applications/select-technology-app-template.png").default} alt="Select React application template" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

3. In the wizard that appears, enter the following details:

    <img src={require("../../../assets/img/guides/applications/create-technology-application.png").default} alt="Create a React application" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    | Parameter | Description |
    | --- | --- |
    | Name | A unique name to identify your application. |
    | Authorized redirect URL | The URL to which the authorization code is sent upon user authentication and where the user is redirected upon logout. |

4. Click **Create** to complete the registration.
