To integrate your web application with {edition.productName} using OpenID Connect, you need to first register your web application as an OpenID Connect web application in {edition.productName}. A client ID and client secret are issued to the application upon registration.

Follow the instructions given below.

## Register the app

To register the app:

1. On the {edition.productName} Console, go to **Applications**.

2. Click **New Application** and select **Traditional Web Application**.

    <img src={require("../../../assets/img/guides/applications/select-app-type.png").default} alt="Select app type" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

3. Enter the following details:

4. Click **Register** to complete the registration.

    <details>
    <summary>Sharing with selected organizations</summary>

    If you have enabled **Allow sharing with organizations** while registering the application, you will see a popup window with the following options.

    <img src={require("../../../assets/img/guides/applications/share-application.png").default} alt="Share the application with organizations" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    | Option | Description |
    | --- | --- |
    | Share with all organizations | If selected, the application will be shared with all existing organizations and any new organizations you may create in the future. |
    | Share with only selected organizations | If selected, you can select the organizations you wish to share the application with. |

    </details>

5. [Enable the application](./index.mdx#enabledisable-an-application) when it is ready for use.

## Get the client ID and secret

When you register your web application, a client ID and client secret are generated. Your web application will identify itself to {edition.productName} with these credentials.

You can get this client ID and client secret from the **Protocol** tab of the application, as shown below.
