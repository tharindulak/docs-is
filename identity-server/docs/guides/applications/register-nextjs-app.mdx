{edition.productName} provides an application template with default configurations to register a Next.js application with minimal effort.

To register a Next.js application,  

1. On the {edition.productName} Console, go to **Applications**.

2. Click **New Application** and select **Next.js**.

    <img src={require("../../../assets/cloud/img/guides/applications/select-technology-app-template.png").default} alt="Select Next.js application template" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

3. In the wizard that appears, enter the following details:

    <img src={require("../../../assets/cloud/img/guides/applications/create-technology-application.png").default} alt="Create a Next.js application" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    | Parameter | Description |
    | --- | --- |
    | Name | A unique name to identify your application. |
    | Authorized redirect URL | The URL to which the authorization code is sent upon user authentication and where the user is redirected upon logout. |

4. Click **Create** to complete the registration.
