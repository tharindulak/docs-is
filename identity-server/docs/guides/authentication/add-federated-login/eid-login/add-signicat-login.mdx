[Signicat’s](https://www.signicat.com/) eID Hub simplifies digital identity verification and authentication by connecting your platform to more than 30 electronic identities (eIDs) from across Europe, all through one streamlined integration.

By integrating Signicat, you can authenticate users and prove their identity easily using trusted eIDs, whether for onboarding, access control, or compliance needs.

You can add Signicat login to your applications using {edition.productName} and enable users to log in with their eIDs.

Follow this guide for instructions.

## Prerequisites
- A Signicat account. If you don't have one, you can [sign up for free](https://developer.signicat.com/docs/).

## Register {edition.productName} on Signicat

You need to register {edition.productName} as an OIDC app on Signicat.

:::note
You can follow the [Signicat documentation](https://developer.signicat.com/docs/) for detailed instructions.
:::

1. Log in to [Signicat Dashboard](https://dashboard.signicat.com), and click .
2. On the left panel, Click **Products** and select **eID Hub**.
3. Under **eID Hub**, click **OIDC Clients**.

    <img src={require("../../../../../assets/img/guides/idp/signicat-idp/signicat-register-app.png").default} alt="Register OIDC app in Signicat" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

4. Give the application a name and the following URLs:

    - **Authorization callback URL**
        ```bash
        {edition.productUrlFormat}/commonauth
        ```

    <img src={require("../../../../../assets/img/guides/idp/signicat-idp/signicat-app-info.png").default} alt="Enter Signicat app details" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

5. Click **Create**.
6. Click **Add Secret** and Generate a new client secret.
7. Take note of the **Client ID** and **Client secret**.
8. To add required eIDs, Click **eIDs** in the left panel (under **eID Hub**), and click **Add new**.
   <img src={require("../../../../../assets/img/guides/idp/signicat-idp/signicat-add-eid.png").default} alt="Add new eID" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

9. Select the eIDs you want to add and click **Add**.

## Register the Signicat Connection

Now, let's register the Signicat IdP in {edition.productName}.

1. On the {edition.productName} Console, go to **Connections**.
2. Click **New Connections** and select **Signicat**.
3. Enter the following details and click **Finish**:

    <Variants><Edition only="cloud"><img src={require("../../../../../assets/img/guides/idp/signicat-idp/add-signicat-idp.png").default} alt="Add Signicat Connection in WSO2 Identity Platform" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../../assets/img/guides/idp/signicat-idp/add-signicat-idp.png").default} alt="Add Signicat Connection in WSO2 Identity Server" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

    | Parameter | Description |
    | --- | --- |
    | Name | A unique name for this Signicat identity provider. |
    | Client ID | The client ID obtained from Signicat. |
    | Client secret | The client secret obtained from Signicat. |
    | Authorised redirect URL | Provide the Authorised redirect URL of your Signicat organization. For example https://\{your_signicat_domain\}/auth/open/connect/authorize.. |
    | Token Endpoint URL | Provide the Token endpoint URL of your Signicat organization. For example https://\{your_signicat_domain\}/auth/open/connect/token. |

## Enable Signicat login

:::note[Before you begin]
You need to [register an application with {edition.productName}](../../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../../get-started/try-samples/index.mdx) provided.
:::

1. On the {edition.productName} Console, go to **Applications**.
2. Select your application, go to the **Login Flow** tab and add Signicat login from your preferred editor:

    <Variants>

    <Edition only="cloud">

    <Tabs groupId="tabs">
    <TabItem value="classic-editor" label="Classic Editor">

    To add Signicat login using the Classic Editor: 

     1. If you haven't already defined a sign-in flow, click **Start with Default configuration** to get started.
     2. Click **Add Authentication** on the step, select your Signicat identity provider, and click **Add**.
        <img src={require("../../../../../assets/cloud/img/guides/idp/signicat-idp/add-signicat-federation-with-basic.png").default} alt="Add Signicat login in WSO2 Identity Platform" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    <TabItem value="visual-editor" label="Visual Editor">

    To add Signicat login using the Visual Editor: 

    1. Switch to the **Visual Editor** tab, by default the `Username & Password` login flow will be added onto the Visual Editor's workspace.
    2. Click on `+ Add Sign In Option` to add a new authenticator to the same step and select your Signicat connection.
      <img src={require("../../../../../assets/cloud/img/guides/idp/signicat-idp/add-signicat-federation-with-visual-editor.png").default} alt="Add Signicat login in WSO2 Identity Platform" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    </Tabs>

    ---

    </Edition>

    <Edition only="self-hosted">

    1. Click **Add Sign In Option** to add a new authenticator to the first step.

    2. Select the Signicat connection.

    3. Click **Confirm** to add login with Signicat to the sign-in flow.

         <img src={require("../../../../../assets/self-hosted/img/guides/idp/signicat-idp/add-signicat-login-with-visual-editor.png").default} alt="Configuring Signicat in WSO2 Identity Server using the Visual Editor" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </Edition>

    </Variants>

    :::note[Recommendations]
    It is recommended to add your social and enterprise connections to the first authentication step as they are used for identifying the user.
    :::

3. Click **Update** to save your changes.

## Try it out

Follow the steps given below.

1. Access the application URL.

2. Click **Login** to open the {edition.productName} login page.

3. On the {edition.productName} login page, **Sign in with Signicat**.

    <img src={require("../../../../../assets/img/guides/idp/signicat-idp/sign-in-with-signicat.png").default} alt="Login with Signicat" width="300" style={{border: "0.3px solid lightgrey"}} />

4. Log in to the eIDs configured in Signicat.
