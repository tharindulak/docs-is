[FranceConnect](https://franceconnect.gouv.fr/) is a digital authentication solution provided by the French government. It allows users to log in to various online services using their FranceConnect credentials. This guide will help you set up FranceConnect login in {edition.productName}.

## Register {edition.productName} on FranceConnect
1. Log in to the [FranceConnect Portal](https://partenaires.franceconnect.gouv.fr/login). 
2. You will get the Client ID and Client Secret from the FranceConnect application.
3. Enter the following as the Redirect URL:
    - **Authorization callback URL**
      ```bash
      {edition.productUrlFormat}/commonauth
      ```

## Register the FranceConnect Login

Now, let's register the FranceConnect in {edition.productName}.

1. On the {edition.productName} Console, go to **Connections**.
2. Click **New Connections** and select **Standard-based Idp**.
3. Click **Create**.
4. Enter a  unique name for your FranceConnect connection.
   <img src={require("../../../../../assets/cloud/img/guides/idp/franceconnect-eid/add-franceconnect-eid.png").default} alt="Add FranceConnect in WSO2 Identity Platform" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />
5. Enter the following details and click **Finish**:

       | Parameter | Description |
       | --- | --- |
       | Client ID | The client ID obtained from FranceConnect. |
       | Client secret | The client secret obtained from FranceConnect. |
       | Authorised redirect URL | Provide the Authorised redirect URL of your FranceConnect connection. For example \`https://app.franceconnect.gouv.fr/api/v1/authorize\`. |
       | Token Endpoint URL | Provide the Token endpoint URL of your FranceConnect connection. For example \`https://app.franceconnect.gouv.fr/api/v1/token\`. |
   <br />
      <img src={require("../../../../../assets/cloud/img/guides/idp/franceconnect-eid/add-franceconnect-wizard.png").default} alt="Enter FranceConnect's Endpoint details WSO2 Identity Platform" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /> 
6. Click **Next**<br />
7. You can enter *JWKS endpoint URL*  of France Connect or upload the public certificate. This step is not mandatory while creating the connection.
      <table>
        <tbody>
          <tr>
            <td>JWKS endpoint URL</td>
            <td>Provide the JWKS endpoint URL of your FranceConnect organization. For example \`https://app.franceconnect.gouv.fr/api/v1/jwks\`.</td>
          </tr>
        </tbody>
      </table>
8. Click **Finish**.

## Enable FranceConnect login

:::note[Before you begin]
You need to [register an application with {edition.productName}](../../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../../get-started/try-samples/index.mdx) provided.
:::

1. On the {edition.productName} Console, go to **Applications**.
2. Select your application, go to the **Login Flow** tab and add FranceConnect login from your preferred editor:

    <Tabs groupId="tabs">
    <TabItem value="classic-editor" label="Classic Editor">

    To add FranceConnect login using the Classic Editor:

     1. If you haven't already defined a sign-in flow, click **Start with Default configuration** to get started.
     2. Click **Add Authentication** on the step, select your FranceConnect identity provider, and click **Add**.
        <img src={require("../../../../../assets/cloud/img/guides/idp/franceconnect-eid/add-franceconnect-federation-with-basic.png").default} alt="Add FranceConnect login in WSO2 Identity Platform" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    <TabItem value="visual-editor" label="Visual Editor">

    To add FranceConnect login using the Visual Editor:

    1. Switch to the **Visual Editor** tab, by default the `Username & Password` login flow will be added onto the Visual Editor's workspace.
    2. Click on `+ Add Sign In Option` to add a new authenticator to the same step and select your FranceConnect connection.
      <img src={require("../../../../../assets/cloud/img/guides/idp/franceconnect-eid/add-franceconnect-federation-with-visual-editor.png").default} alt="Add FranceConnect login in WSO2 Identity Platform" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    </Tabs>

    ---

    :::note[Recommendations]
    It is recommended to add your social and enterprise connections to the first authentication step as they are used for identifying the user.
    :::

3. Click **Update** to save your changes.
