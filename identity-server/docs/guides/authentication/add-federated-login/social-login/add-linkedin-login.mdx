You can add LinkedIn login to your applications using {edition.productName} and enable users to log in with their LinkedIn accounts.  

Follow this guide for instructions.

## Register {edition.productName} on LinkedIn
You need to register {edition.productName} as an OAuth2.0 application on LinkedIn.

1. Go to the [LinkedIn Developer console](https://developer.linkedin.com/), click on **Create app** button to create a new application.

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/create-app.png").default} alt="Create a new application" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

2. Provide the **App name**, **LinkedIn Page**, and **App logo** for your application. Accept the **Legal agreement** and click on **Create app** to complete the application creation process.

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/create-app-wizard.png").default} alt="Application create wizard" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

3. In the **Products** tab, request access for **Sign In with LinkedIn using OpenID Connect**.

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/request-access-oidc.png").default} alt="Request access for sign in with LinkedIn using OpenID Connect" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

4. Navigate to the **Auth** tab and add the following URL as the **Authorized Redirect URL** for your app.

    ```bash
    {edition.productUrlFormat}/commonauth
    ```

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/auth-redirect-url.png").default} alt="Authorized Redirect URL" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

7. Take note of the client ID and client secret generated for the application from the **Auth** tab.

## Register the LinkedIn IdP

Now, let's register the LinkedIn IdP in {edition.productName}.

1. On the {edition.productName} Console, go to **Connections**.
2. Click **New Connections** and select **LinkedIn**.
3. Enter the following details of the LinkedIn identity provider and click **Create**:

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/add-linkedin-idp.png").default} alt="Add LinkedIn IDP in WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} />

    | Parameter | Description |
    | --- | --- |
    | Name | A unique name for this LinkedIn identity provider. |
    | Client ID | The client ID obtained from LinkedIn. |
    | Client secret | The client secret obtained from LinkedIn. |

## Enable LinkedIn login

:::note[Before you begin]
You need to [register an application with {edition.productName}](../../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../../get-started/try-samples/index.mdx) provided.
:::

1. On the {edition.productName} Console, go to **Applications**.
2. Select your application, go to the **Login Flow** tab and add LinkedIn login from your preferred editor:

    <Tabs groupId="tabs">
    <TabItem value="classic-editor" label="Classic Editor">

    To add LinkedIn login using the Classic Editor:

    1. If you haven't already defined a sign-in flow, click **Start with Default configuration** to get started.

    2. Click **Add Authentication** on the step, select your LinkedIn identity provider, and click **Add**.

        <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/add-linkedin-federation-with-basic.png").default} alt="Add LinkedIn login in WSO2 Identity Platform" width="700" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    <TabItem value="visual-editor" label="Visual Editor">

    To add LinkedIn login using the Visual Editor:

    1. Switch to the **Visual Editor** tab, by default the `Username & Password` login flow will be added onto the Visual Editor's workspace.

    2. Click on `+ Add Sign In Option` to add a new authenticator to the same step and select your LinkedIn connection.

        <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/add-linkedin-login-with-visual-editor.png").default} alt="add LinkedIn login in WSO2 Identity Platform using the Visual Editor" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    </Tabs>

    ---

    :::note[Recommendations]
    It is recommended to add your social and enterprise connections to the first authentication step as they are used for identifying the user.
    :::

3. Click **Update** to save your changes.

## Try it out

Follow the steps given below.

1. Access the application URL.
2. Click **Login** to open the {edition.productName} login page.
3. On the {edition.productName} login page, **Sign in with LinkedIn**.

    <img src={require("../../../../../assets/cloud/img/guides/idp/linkedin-idp/sign-in-with-linkedin.png").default} alt="Login with LinkedIn" width="300" style={{border: "0.3px solid lightgrey"}} />

4. Log in to LinkedIn with an existing user account.

:::note
When a user successfully logs in with LinkedIn for the first time, a **user** account is created in the {edition.productName} Console with the LinkedIn email. This new user account will be managed by LinkedIn.
:::
