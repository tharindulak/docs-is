You can add Facebook login to your applications using {edition.productName} and enable users to log in with their Facebook accounts.

Follow this guide for instructions.

## Register {edition.productName} on Facebook
You need to register {edition.productName} as an app on Facebook.

:::note
You can follow the [Facebook Documentation](https://developers.facebook.com/docs/development/create-an-app) for detailed instructions.
:::

To register an app on Facebook:

1. Go to the [My Apps](https://developers.facebook.com/apps) page in **Meta for developers**.

2. Click **Create App**.

    <img src={require("../../../../../assets/img/guides/idp/facebook-idp/facebook-developer-portal.jpg").default} alt="Facebook developer portal" width="600" style={{border: "0.3px solid lightgrey"}} />

3. Select the use case as **Authenticate and request data from users with Facebook Login** and click **Next**.

    <img src={require("../../../../../assets/img/guides/idp/facebook-idp/facebook-app-type.jpg").default} alt="Create Facebook consumer app" width="600" style={{border: "0.3px solid lightgrey"}} />

4. Select the login type out of the options and click **Next**.

    <img src={require("../../../../../assets/img/guides/idp/facebook-idp/facebook-choose-login-type.png").default} alt="Choose login type" width="600" style={{border: "0.3px solid lightgrey"}} />

5. Provide **Display Name** and click **Create App** to create an application.

    <img src={require("../../../../../assets/img/guides/idp/facebook-idp/facebook-app-info.jpg").default} alt="Provide information to Facebook app" width="600" style={{border: "0.3px solid lightgrey"}} />

6. While in the created application, select **Use cases** from the left navigation.

7. Under **Use cases** > **Authentication and account creation**, click **Customize**.

8. Under **Facebook Login** > **Quickstart**, click **Go to quickstart**.

9. Select **Web** as the platform for this app and provide the following **Site URL** and click **Save**.

    ```bash
    {edition.productUrlFormat}
    ```

10. Return to the **Use cases** > **Customize** section and under **Facebook login** > **Settings**, click **Go to settings**.

11. Add the following as the **Valid OAuth Redirect URIs** and click **Save changes**.

    ```bash
    {edition.productUrlFormat}/commonauth
    ```

12. Enable **Client OAuth Login** and **Web OAuth Login** (these are enabled by default) and save the changes.

    <Variants><Edition only="cloud"><img src={require("../../../../../assets/cloud/img/guides/idp/facebook-idp/facebook-app-settings.jpg").default} alt="Add Facebook settings" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../../assets/self-hosted/img/guides/idp/facebook-idp/facebook-app-settings.jpg").default} alt="Add Facebook settings" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

13. On the left navigation panel, go to **App settings** > **Basic** and take note of the **App ID** and **App Secret**.

    <Variants><Edition only="cloud"><img src={require("../../../../../assets/cloud/img/guides/idp/facebook-idp/app-id-secret-from-facebook.png").default} alt="Get AppID and Secret from Facebook" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../../assets/self-hosted/img/guides/idp/facebook-idp/app-id-secret-from-facebook.png").default} alt="Get AppID and Secret from Facebook" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

## Register the Facebook IdP

Now, let's register the Facebook IdP in {edition.productName}.

1. On the {edition.productName} Console, go to **Connections**.
2. Click **Create Connection** and select **Facebook**.
3. Enter the following details of the Facebook identity provider and click **Finish**:

    <Variants><Edition only="cloud"><img src={require("../../../../../assets/cloud/img/guides/idp/facebook-idp/add-facebook-idp.png").default} alt="Add Facebook IDP in WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../../assets/self-hosted/img/guides/idp/facebook-idp/add-facebook-idp.png").default} alt="Add Facebook IDP in WSO2 Identity Server" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

    | Parameter | Description |
    | --- | --- |
    | Name | A unique name for this Facebook identity provider. |
    | App ID | App ID obtained from Facebook. |
    | App Secret | The app secret obtained from Facebook. |

{/* 4. If required, you can [disable JIT user provisioning]({{base_path}}/guides/authentication/jit-user-provisioning/). */}

5. Go to the **Settings** tab and see the list of permissions granted by Facebook to {edition.productName}.

    - **email**: Grants read access to a user's primary email address.
    - **public_profile**: Grants read access to a user's default public profile details.  

    :::note
    {edition.productName} needs these permissions to get user information. {edition.productName} checks the attribute configurations of the application and sends the relevant attributes received from Facebook to the app. You can read the [Facebook documentation](https://developers.facebook.com/docs/permissions/reference) to learn more.
    :::

## Enable Facebook login

:::note[Before you begin]
You need to [register an application with {edition.productName}](../../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../../get-started/try-samples/index.mdx) provided.
:::

1. On the {edition.productName} Console, go to **Applications**.
2. Select your application, go to the **Login Flow** tab and add Facebook login as follows:

    <Edition only="cloud">

    1. If you haven't already defined a sign-in flow, click **Start with Default configuration** to get started.

    2. Click **Add Authentication** on the step, select your Facebook identity provider, and click **Add**.

    </TabItem>
    <TabItem value="visual-editor" label="Visual Editor">

    1. Switch to the **Visual Editor** tab, by default the `Username & Password` login flow will be added onto the Visual Editor's workspace.

    2. Click on `+ Add Sign In Option` to add a new authenticator to the same step and select your Facebook connection.

        <img src={require("../../../../../assets/img/guides/idp/facebook-idp/add-facebook-login-with-visual-editor.png").default} alt="Add Facebook login in WSO2 Identity Platform using the Visual Editor" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </Edition>

    <Edition only="self-hosted">

    2. Select the Facebook connection.

    3. Click **Confirm** to add login with Facebook to the sign-in flow.

        <img src={require("../../../../../assets/img/guides/idp/facebook-idp/add-facebook-login-with-visual-editor.png").default} alt="Configuring Facebook login in WSO2 Identity Server using the Visual Editor" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    :::note[Recommendations]
    It is recommended to add your social and enterprise connections to the first authentication step as they are used for identifying the user.

3. Click **Update** to save your changes.

## Try it out

Follow the steps given below.

1. Access the application URL.

2. Click **Login** to open the {edition.productName} login page.

3. On the {edition.productName} login page, click **Sign in with Facebook**.

    <Variants><Edition only="cloud"><img src={require("../../../../../assets/cloud/img/guides/idp/facebook-idp/sign-in-with-facebook.png").default} alt="Login with Facebook" width="300" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../../assets/self-hosted/img/guides/idp/facebook-idp/sign-in-with-facebook.png").default} alt="Login with Facebook" width="300" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

4. Log in to Facebook with an existing user account.

5. The user is now redirected to the application and logged in.

:::note
When a user successfully logs in with Facebook for the first time, a **user** account is created in the {edition.productName} Console with the Facebook username. This new user account will be managed by Facebook.
:::
