# Log in to Zoom using {edition.productName}

This page guides you through integrating {edition.productName} for Single Sign-On (SSO) with Zoom.

:::note[Before you begin]
You need to have a Zoom account that supports SSO. Refer to the [Zoom documentation](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060673) for more details.
:::

## Create the Zoom application

Follow the steps given below to register the Zoom application in {edition.productName}.

1. On the {edition.productName} Console, go to **Applications**.

2. Click **New Application** and under **SSO Integrations**, select **Zoom**..

    <Variants><Edition only="cloud"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/common/add-app.png").default} alt="Select app type in the WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/common/add-app.png").default} alt="Select app type in the WSO2 Identity Server" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

3. Provide the Zoom domain name and a name for the application.

    :::info[Domain Name]
    Zoom domain name is the first part of your Zoom vanity URL. If your vanity URL is `https://myorg.zoom.us`, enter `myorg` as the Domain Name. Follow Zoom's guidelines to [request your vanity URL](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0061540)
    :::

    <Variants><Edition only="cloud"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/zoom/add-zoom-app.png").default} alt="Select Zoom workspace app in the WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/zoom/add-zoom-app.png").default} alt="Select Zoom workspace app in the WSO2 Identity Server" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

4. Click **Create** to complete the registration.

## Try it out

Now that you have integrated {edition.productName} with Zoom, follow the steps below to test it.

1. Create a user in {edition.productName} and ensure the same user exists in your Zoom organization with the same email address.

2. Navigate to the [Zoom SSO sign-in page](https://zoom.us/web/sso/login?en=signin#/sso) and enter the company domain. You will then be redirected to the {edition.productName} login screen.

3. Enter the username and password of the user and complete the login process.

## Troubleshooting guidelines

To troubleshoot SSO failures on the Zoom side, refer to the SAML response logs. Follow [Zoom documentation](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0061276) to learn more.
