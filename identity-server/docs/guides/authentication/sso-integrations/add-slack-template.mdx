# Log in to Slack using {edition.productName}

This page guides you through integrating {edition.productName} for Single Sign-On (SSO) with Slack.

:::note[Before you begin]
You need to have a Slack Workspace account that supports SSO. Refer to the [Slack documentation](https://slack.com/intl/en-gb/help/articles/203772216-SAML-single-sign-on) for more details.
:::

## Create the Slack application

Follow the steps given below to register the Slack application in {edition.productName}.

1. On the {edition.productName} Console, go to **Applications**.

2. Click **New Application** and under **SSO Integrations**, select **Salck**.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/common/add-app.png").default} alt="Select app type in the WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/common/add-app.png").default} alt="Select app type in the WSO2 Identity Server" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

3. Provide a name for your application and the following values:

    - **Issuer Name** - By default, Slack uses `https://slack.com` as the issuer name. You only need to modify this setting if you are creating multiple Slack SSO applications. If you choose to use the `Slack Workspace URL` as the issuer name instead, ensure that the configuration in Slack is updated accordingly to reflect this change.

    - **Domain Name** - Slack domain name is the first part of your Slack workspace URL. For example, if it is `https://myorg.slack.com`, enter `myorg` as the domain name. 

        :::note
        Follow Slack's guidelines to [locate your Slack URL](https://slack.com/intl/en-gb/help/articles/221769328-Locate-your-Slack-URL-or-ID).
        :::

    <Variants><Edition only="cloud"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/slack/add-slack-app.png").default} alt="Select slack workspace app in the WSO2 Identity Platform" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/img/guides/authentication/sso-integrations/slack/add-slack-app.png").default} alt="Select slack workspace app in the WSO2 Identity Server" width="600" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

4. Click **Create** to complete the registration.

## Try it out

Now that you have integrated {edition.productName} with Slack, follow the steps below to test it.

:::note
When the workspace owner enables SSO for the Slack workspace, existing users will receive an email to their registered email addresses to bind their {edition.productName} account. New users will be auto-provisioned during login. For more details, refer to Slack documentation on [What to expect after SSO is enabled](https://slack.com/intl/en-gb/help/articles/203772216-SAML-single-sign-on#what-to-expect) and [Sign in to Slack](https://slack.com/intl/en-gb/help/articles/212681477-Sign-in-to-Slack).
:::

1. Create a user in {edition.productName}.

2. Navigate to [https://slack.com/workspace-signin](https://slack.com/workspace-signin) and enter the Slack workspace URL. This will take you to the workspace login page, where you can choose to sign-in with SSO. You will then be redirected to the {edition.productName} login screen.

3. Enter the username and password of the user you created in {edition.productName}, and complete the login process.
