## Prerequisites

[Register your application](../add-login-to-apps/add-login-to-apps.mdx) on the {edition.productName} Console.

## Enable conditional authentication

{/* markdownlint-disable-next-line */}
Follow the steps given below.

1. On the {edition.productName} Console, click **Applications**.
2. Select the application for which you wish to apply a conditional login flow and go to its **Login Flow** tab.
3. Click **Start with default configuration** to define the login flow starting with the `username and password` login.
4. Turn on **Conditional Authentication** by switching the toggle on. You can define your conditional authentication script in the editor.

    <Variants><Edition only="cloud">![Enable conditional auth](../../../../assets/cloud/img/guides/conditional-auth/enable-conditional-auth.png)</Edition><Edition only="self-hosted">![Enable conditional auth](../../../../assets/self-hosted/img/guides/conditional-auth/enable-conditional-auth.png)</Edition></Variants>

    :::warning
    As a security measure, {edition.productName} does not allow the usage of two consecutive periods (`..`) in authentication scripts.
    :::

## Add conditional authentication script

There are two ways to add a conditional authentication script:

- Use a [predefined template](./index.mdx#script-templates).
- Write a [new conditional auth script](./write-your-first-script.mdx).

:::warning[Before you proceed]
When working with conditional authentication scripts, <b>never log secrets</b> or <b>sensitive information</b> within your authentication flows.
:::

## Add a secret to the script
Secrets securely store values associated with external APIs. These secret values are used in conditional authentication scripts when {edition.productName} is required to interact with an external API (service endpoint) during the authentication process.

You can securely store these secret values on the {edition.productName} Console and retrieve them whenever required for conditional authentication script.

### Create a new secret

To add a new secret:

1. On the {edition.productName} Console, go to **Applications**.

2. Select your application and go to the **Login Flow** tab .

3. Add a new secret from your preferred editor:

6. Click **Finish** to complete the creation.

### Use secret in the script

You may refer to the previously added secrets in your conditional authentication scripts using the `secrets.{secret name}` syntax. For example, to retrieve a secret value, you may use:

```markup
var secretValue = secrets.secretName;
```

This allows you to securely access secret values within your authentication scripts, enhancing the security and flexibility of your authentication process.
