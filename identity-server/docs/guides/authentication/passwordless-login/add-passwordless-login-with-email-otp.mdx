Email OTP is a form of passwordless authentication. It allows users to log in by providing a one-time passcode sent to their email instead of entering a password.

## Prerequisites
- To get started, you need to [register an application with {edition.productName}](../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../get-started/try-samples/index.mdx) provided.

<Variants>

<Edition only="cloud">

- You need to have a user account in {edition.productName}. If you don't already have one, [create a user account](../../users/users/manage-users.mdx#onboard-users) in {edition.productName}.

    :::note
    You cannot use an administrator account to log in to an application.
    :::

</Edition>

<Edition only="self-hosted">

- You need to have a user account in {edition.productName}. If you don't already have one, [create a user account](../../users/users/manage-users.mdx#onboard-users) in {edition.productName}.

- You need to [configure the email sending module](../../notification-channels/configure-email-provider.mdx) for the WSO2 Identity Server to send the email OTP to the users.

</Edition>

</Variants>

## Enable Email OTP login for an app

Follow the steps given below to add **Email OTP** login to the login flow of your application.

1. On the {edition.productName} Console, go to **Applications**.

2. Select the application to which you wish to add email OTP login.

<Variants>

<Edition only="cloud">

3. Go to the **Login Flow** tab of the application and add email OTP login as follows:

    <Tabs groupId="tabs">
    <TabItem value="visual-editor" label="Visual Editor">

    To add passwordless login with email OTP using the Visual Editor:

    1. Switch to the **Visual Editor** tab and go to **Predefined Flows** > **Basic Flows** > **Add Passwordless login**.

    2. Select **Email OTP**.

    3. Click **Confirm** to add passwordless login with email OTP to the sign-in flow.

        <img src={require("../../../../assets/img/guides/passwordless/email-otp/add-email-otp-login-step-with-visual-editor.png").default} alt="Configuring email OTP login in WSO2 Identity Platform using the Visual Editor" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    <TabItem value="classic-editor" label="Classic Editor">

    - If you haven't already built a login flow for your application, select **Add Email OTP login** to build one.

        <img src={require("../../../../assets/cloud/img/guides/passwordless/email-otp/add-email-otp-login.png").default} alt="Configuring email OTP login in WSO2 Identity Platform" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    - If you have an already built login flow, add the **Email OTP** authenticator as the first authentication step.

        <img src={require("../../../../assets/cloud/img/guides/passwordless/email-otp/add-email-otp-login-step.png").default} alt="Customize the login flow" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    </Tabs>

    ---

</Edition>

<Edition only="self-hosted">

3. Go to the **Login Flow** tab of the application and add email OTP login as follows:

    1. Go to **Predefined Flows** > **Basic Flows** > **Add Passwordless login**.

    2. Select **Email OTP**.

    3. Click **Confirm** to add passwordless login with email OTP to the sign-in flow.

        <img src={require("../../../../assets/img/guides/passwordless/email-otp/add-email-otp-login-step-with-visual-editor.png").default} alt="Configuring magic link login in WSO2 Identity Server using the Visual Editor" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

</Edition>

</Variants>

4. Click **Update** to save your changes.

## Try it out

Follow the steps given below.

1. Access the application URL.
2. Click **Login** to open the {edition.productName} login page.
3. On the {edition.productName} login page, enter your username and press **Continue**.
