Magic link is a form of passwordless authentication. It allows users to log in by clicking a link sent to their email instead of entering a password.

## Prerequisites

- To get started, you need to [register an application with {edition.productName}](../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../get-started/try-samples/index.mdx) provided.

<Variants>

<Edition only="cloud">

- You need to have a user account in {edition.productName}. If you don't already have one, [create a user account](../../users/users/manage-users.mdx#onboard-users) in {edition.productName}.

    :::note
    You cannot use an administrator account to log in to an application.
    :::

</Edition>

<Edition only="self-hosted">

- You need to have a user account in {edition.productName}. If you don't already have one, [create a user account](../../users/users/manage-users.mdx#onboard-users) in {edition.productName}.

- You need to [configure the email sending module](../../../deploy-and-operate/configure/email-sending-module.mdx) for the WSO2 Identity Server to send the Magic link to the users.

</Edition>

</Variants>

## Enable Magic link login for an app

Follow the steps given below to add **Magic link** login to the login flow of your application.

1. On the {edition.productName} Console, go to **Applications**.

2. Select the application to which you wish to add magic link login.

<Variants>

<Edition only="cloud">

3. Go to the **Login Flow** tab of the application and add magic link login as follows:

    <Tabs groupId="tabs">
    <TabItem value="visual-editor" label="Visual Editor">

    To add passwordless login with magic link using the Visual Editor:

    1. Go to **Predefined Flows** > **Basic Flows** > **Add Passwordless login**.

    2. Select **Magic Link**.

    3. Click **Confirm** to add passwordless login with Magic Link to the sign-in flow.

        <img src={require("../../../../assets/cloud/img/guides/passwordless/magic-link/add-magic-link-login-with-visual-editor.png").default} alt="Configuring magic link login in WSO2 Identity Platform using the Visual Editor" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    <TabItem value="classic-editor" label="Classic Editor">

    To add passwordless login with magic link using the Classic Editor:

    - Select **Add Magic Link login** from the list if you haven't already built a login flow for the application.

        <img src={require("../../../../assets/cloud/img/guides/passwordless/magic-link/add-magic-link-login.png").default} alt="Configuring magic link login in WSO2 Identity Platform" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    - If you already have a login flow, click **Add authentication**, select **Magic Link** and click **Add** in the first authentication step.

        <img src={require("../../../../assets/cloud/img/guides/passwordless/magic-link/add-magic-link-login-step.png").default} alt="Customize the login flow" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    </TabItem>
    </Tabs>

    ---

</Edition>

<Edition only="self-hosted">

3. Go to the **Login Flow** tab of the application and add magic link login as follows:

    1. Go to **Predefined Flows** > **Basic Flows** > **Add Passwordless login**.

    2. Select **Magic Link**.

    3. Click **Confirm** to add passwordless login with magic link to the sign-in flow.

        <img src={require("../../../../assets/self-hosted/img/guides/passwordless/magic-link/add-magic-link-login.png").default} alt="Configuring magic link login in WSO2 Identity Server using the Visual Editor" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

4. Click **Update** to save your changes.

    :::note

    :::

<Edition only="self-hosted">

5. Open the magic link by clicking the **Sign In** button.

    :::note
    Magic links support cross-browser functionality, allowing you to open the link and log in from any browser of your choice even if it is different from the one you used to initiate the login process.
    If you want to remove the cross-browser functionality, you can do so by adding the following configuration in the `deployment.toml` file found in the `<IS_HOME>/repository/conf/` directory.

    ```toml
       [session.nonce.cookie]
       default_whitelist_authenticators=[] 
    ```
    This configuration ensures that the magic link can only be opened using the same browser from which the login was initiated.
    :::

</Edition>

</Variants>
