An SMS one-time password (OTP) delivers a short-lived code to the user’s registered mobile number. This works as a passwordless authentication mechanism, allowing users to log in without a password by entering the OTP received via SMS.

Follow the instructions given below to implement passwordless login using SMS OTP in {edition.productName}.

## Prerequisites

- To begin, you must [register an application with {edition.productName}](../../applications/index.mdx). You have the option to register your own application or use one of the [sample applications](../../../get-started/try-samples/index.mdx) available.

- Ensure you have a user account in {edition.productName}. If not, you can [create a user account](../../users/users/manage-users.mdx#onboard-users) within {edition.productName}.

- [Update the user profile of the users](../../users/users/manage-users.mdx#update-the-profile) with an mobile number to which the user will receive the OTP.

<Variants>

<Edition only="cloud">

- Configure your preferred SMS provider in {edition.productName}. For detailed instructions, see [Configure SMS providers](../../notification-channels/configure-sms-provider.mdx).

    :::note
    You cannot use an administrator account to log in to an application.
    :::

</Edition>

<Edition only="self-hosted">

- Configure your preferred SMS provider in {edition.productName}. For detailed instructions, see [Configure SMS providers](../../notification-channels/configure-sms-provider.mdx).

</Edition>

</Variants>

## Configure SMS OTP

To update the default SMS OTP settings:

1. On the {edition.productName} Console, go to **Connections** and select **SMS OTP**.
2. Update the following parameters in the **Settings** tab:
   <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/sms-otp/setup-sms-otp.png").default} alt="Setup SMS OTP in WSO2 Identity Platform" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/sms-otp/setup-sms-otp.png").default} alt="Setup SMS OTP in WSO2 Identity Server" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>
   | Field | Description |
   | --- | --- |
   | `SMS OTP expiry time` | Specifies the OTP expiry time. The generated OTP won't be valid after this time. |
   | `Use only numeric characters for OTP` | Specifies whether to use only numeric characters in the OTP. If this is selected, the generated OTP contains only digits (0-9). If this option is not selected, the OTP will contain alphanumeric characters. |
   | `SMS OTP length` | Specifies the number of characters allowed in the OTP. |
   | `Allowed OTP resend attempt count` | Specifies the number of allowed OTP resend attempts. |
3. Once you update the SMS OTP settings, click **Update**.

## Enable SMS OTP login for your app

Follow the steps given below to add **SMS OTP** login to the login flow of your application.

1. On the {edition.productName} Console, go to **Applications**.

2. Select the application to which you wish to add SMS OTP login.

<Variants>

<Edition only="cloud">

## Try it out

Follow these steps to test the SMS OTP login:

1. Visit the application URL.
2. Click **Login** to bring up the {edition.productName} login page.
3. On the login page, enter your username and click **Continue**.

    This action redirects you to the SMS OTP page.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/sms-otp/sms-otp-submit-page.png").default} alt="SMS OTP submit page" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/sms-otp/sms-otp-submit-page.png").default} alt="SMS OTP submit page" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

4. Check your phone for the SMS containing the one-time password (OTP).

5. Enter the received OTP on the SMS OTP page and click **Continue**.
