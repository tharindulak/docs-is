Push notifications enable a secure and seamless passwordless authentication mechanism by allowing users to verify their identity with a simple tap on their registered mobile device. Instead of relying on traditional passwords or one-time passcodes, authentication requests are securely delivered via push notifications, ensuring real-time, user-friendly login.

This method enhances security by reducing the risk of phishing and credential-based attacks while offering a frictionless login experience. Users can authenticate from any trusted device with internet access, eliminating the need to remember or enter passwords.

To configure push notifications as a passwordless authentication mechanism in {edition.productName}, follow the instructions below.

## Prerequisites

- To get started, you need to [register an application with {edition.productName}](../../applications/index.mdx). You can register your own application or use one of the [sample applications](../../../get-started/try-samples/index.mdx) provided.

- You need to configure a Push Provider in {edition.productName}. If you haven't configured a Push Notification Provider yet, follow the instructions in the [Push Provider Configuration](../../notification-channels/configure-push-provider.mdx) guide.

- You need to have a user account in {edition.productName}. If you don't already have one, [create a user account](../../users/users/manage-users.mdx#onboard-users) in {edition.productName}.

- A push authenticator application is required for the purpose of receiving push notifications. Learn how to [build your own push authenticator app.](../../../reference/tutorials/build-your-own-push-authenticator-app.mdx)

- If push notification device progressive enrollment is disabled, [application users](../../users/users/manage-users.mdx#onboard-users) need to register their push notification devices via the My Account app prior to using push notification based login. Be sure to educate your users on how to [enroll push notification devices via My Account.](../../user-self-service/self-service-portal/register-push-notification-device.mdx)

## Set up Push Notifications

{edition.productName} has some default settings for Push Notifications, which are sufficient for most cases. If required, you can change the default settings, as explained below.

To update the default Push Notification settings:

1. On the {edition.productName} Console, go to **Connections** and select **Push Notification**.
2. Update the following parameters in the **Settings** tab:

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/mfa/push/setup-push-auth.png").default} alt="Setup Push Notifications in WSO2 Identity Platform" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/mfa/push/setup-push-auth.png").default} alt="Setup Push Notifications in WSO2 Identity Server" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

    | Field | Description |
    | --- | --- |
    | `Enable number Challenge` | When enabled, users must confirm the number displayed in the application on their push authentication device to complete the sign in. |
    | `Enable push notification device progressive enrollment` | When enabled, users may enroll their devices for push authentication at the moment they log in to the application. |
    | `Push notification resend interval` | Specifies the time interval between the resend attempts. Also, the polling to identify user's response for the push notification will be ended once the timer is completed. |
    | `Allowed push notification resend attempts` | The number of allowed push notification resend attempts. Once exceeded, the user will not be allowed to send any push notifications. |

3. Once you update the Push Notification settings, click **Update**.

## Enable push notifications login for an app

Follow the steps given below to enable **Push Notification** login for your application.

1. On the {edition.productName} Console, go to **Applications**.

2. Select the application to which you wish to add Push Notification.

3. Go to the **Login Flow** tab of the application and add Push Notification from your preferred editor:

    <Edition only="self-hosted">

    1. Click **+** to add a second step to the login flow.

    2. Click **Add Sign In Option**, select **Push Notification** and click **Add**.

    3. Click **Confirm** to add login with push notifications to the sign-in flow.

4. Click **Update** to save your changes.

## Enable push notification device progressive enrollment

This feature allows users to enroll their push notification devices seamlessly during the usual login flow, offering a blend of convenience and security. Follow the steps given below to enable **Push Notification Devices progressive enrollment** for your application.

1. On the {edition.productName} Console, go to **Connections**.

2. Select the **Push Notification** connection.

3. Go to the **Settings** tab of the connection.

4. Enable the option for **Enable push notification device progressive enrollment** by checking its checkbox.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/mfa/push/enable-push-progressive-enrollment.png").default} alt="Enable push notification device progressive enrollment in WSO2 Identity Platform" width="700" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/mfa/push/enable-push-progressive-enrollment.png").default} alt="Enable push notification device progressive enrollment in WSO2 Identity Server" width="700" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

5. Click **Update** to save your changes.

6. [Add the push notification device progressive enrollment adaptive script](../conditional-auth/specialized-scenarios/push-device-progressive-enrollment-based-template.mdx) to the login flow of the application.

:::note
Push notification device progressive enrollment can only be configured at the organizational level and cannot be modified at the application level.
:::

## Enable progressive enrollment for multiple devices

When multiple device registration is enabled, you can also let a user who already has a registered device add another one during sign-in.

:::warning
Anyone who gets past the earlier authentication step can register their own device during sign-in. Enable this option only if your use case requires it.
:::

1. On the {edition.productName} Console, go to **Connections** > **Push Notification** and open the **Settings** tab.

2. With **Enable push notification device progressive enrollment** and **Allow users to register multiple devices** both enabled, select **Allow progressive enrollment for multiple devices** and confirm the security prompt.

3. Click **Update**.

:::note
For the full walkthrough — enabling multiple device registration, registering additional devices, and device registration notifications — see [Register multiple devices for push notifications](../../../get-started/tutorials/register-multiple-devices-for-push-notifications.mdx).
:::

</Edition>

## Try out Push Notification passwordless login flow with a user already enrolled with a device

In this section, we will guide you through the steps to authenticate using Push Notification passwordless login with a user who has already enrolled a push notification device.

1. Access the application URL.

2. Click **Login** to access the {edition.productName} login page.

3. On the login page, enter your username and click **Continue**.

    This action redirects you to the Push Notification Wait page.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/push/push-auth-wait-page.png").default} alt="Push Notification Wait page" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/push/push-auth-wait-page.png").default} alt="Push Notification Wait page" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

## Try out Push Notification passwordless login flow with a user not enrolled with a device

In this section, we will guide you through the steps to authenticate using Push Notification passwordless login with a user who has not enrolled a push notification device when progressive enrollment is enabled.

1. Access the application URL.

2. Click **Login** to access the {edition.productName} login page.

3. On the login page, enter your username and click **Continue**.

4. Since you have not enrolled a push notification device, you will be shown the following page to get your consent to enroll a push notification device. Click on **Register** to enroll a push notification device.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/push/push-device-enroll-consent.png").default} alt="Push Notification Device Enrollment Consent" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/push/push-device-enroll-consent.png").default} alt="Push Notification Device Enrollment Consent" width="400" style={{border: "0.3px solid lightgrey"}} /></Edition></Variants>

5. Since this authentication flow has not authenticated the user yet, you will be prompted to enter the password of the user account. This is to ensure that the user is the legitimate owner of the account.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/push/push-device-enroll-password-verification.png").default} alt="Push Notification Password Verification" width="400" /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/push/push-device-enroll-password-verification.png").default} alt="Push Notification Password Verification" width="400" /></Edition></Variants>

6. Click on **Sign In** to proceed.

7. If authentication is successful, you will be shown the following page to scan the QR code using your Push Authenticator App to enroll your device. Once the device is enrolled successfully, check the checkbox and click **Continue** to proceed with the authentication.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/push/push-auth-enroll-page.png").default} alt="Push Notification Device Enrollment" width="400" /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/push/push-auth-enroll-page.png").default} alt="Push Notification Device Enrollment" width="400" /></Edition></Variants>

8. You will receive a push notification on your registered device. Approve the authentication request from the registered device.

9. Once you approve the authentication request, you will be successfully logged in to the application.
