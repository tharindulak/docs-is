Users can discover applications that they can access within the organization by following the steps below.

:::note
Administrators should go to the General tab of an application registered in {edition.productName} and enable the <b>Discoverable application</b> option to [make an application discoverable](../../applications/index.mdx#make-an-application-discoverable) in the My Account portal.
:::

1. In the user's MyAccount portal, navigate to **Applications**.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/img/guides/users/discover-apps.png").default} alt="Discover applications in WSO2 Identity Platform MyAccount" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/img/guides/users/discover-apps.png").default} alt="Discover applications in WSO2 Identity Server MyAccount" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

2. In the **All Applications** section, users can view all the applications discoverable to them.

3. Users can click on any application and get redirected to its landing page.
