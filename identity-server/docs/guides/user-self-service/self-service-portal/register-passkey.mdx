Application users can use the My Account portal to enroll their passkeys for [passwordless login](../../authentication/passwordless-login/add-passwordless-login-with-passkey.mdx).

1. In the user's My Account portal, go to **Security** > **Additional Authentication**.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/passkey/register-security-key-via-myaccount.png").default} alt="Enroll passkey via MyAccount" width="800" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/passkey/register-security-key-via-myaccount.png").default} alt="Enroll passkey via MyAccount" width="800" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

2. Click the **+** icon next to **Passkey** and follow the instructions given by the browser.

3. Once it's done, you will get the following prompt.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/passwordless/passkey/rename-security-key-via-myaccount.png").default} alt="Rename passkey via MyAccount" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/passwordless/passkey/rename-security-key-via-myaccount.png").default} alt="Rename passkey via MyAccount" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

4. Provide a name for your device and click **Save**.
