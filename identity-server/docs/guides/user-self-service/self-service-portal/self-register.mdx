If an administrator has enabled self-registration for an organization, users can sign up and create their own accounts without the involvement of an administrator.

:::note
Learn how administrators can [enable self-registration](../../flows/self-registration.mdx) in an organization.
:::

## Self-registration methods

There are two ways that a user can self-register to an organization in {edition.productName}.

### via My Account

To self-register from the My Account portal, the user should follow these steps.

1. Go to the My Account Portal.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/organization/self-service/customer/create-an-account.png").default} alt="Self register to organization" width="400" style={{display: "block", margin: "0"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/organization/self-service/customer/create-an-account.png").default} alt="Self register to organization" width="400" style={{display: "block", margin: "0"}} /></Edition></Variants>

2. Click **Register**.

3. Follow the steps to [sign-up using an email](#sign-up-using-an-email).

### via an application

To self-register from an application, users should follow these steps.

1. Access the application URL.
2. Click **Register**
3. Select one of the following options to sign up:

    - Click **Continue with email** and follow the steps to [sign up using an email](#sign-up-using-an-email).
    - Sign-up using any of the other authenticators as shown below.

      <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/organization/self-service/customer/self-registration-select-a-method.png").default} alt="Account verification email notification" width="400" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/organization/self-service/customer/self-registration-select-a-method.png").default} alt="Account verification email notification" width="400" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

## Sign up using an email

A user can sign-up to an organization in {edition.productName} using an email, [via My Account portal](#via-my-account) or [via an application](#via-an-application).

The user can follow the steps below to sign up using an email.

1. Click **Continue with email** on the sign-up screen.

2. Enter the email address, password, and any other information that the application requests.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/organization/self-service/customer/self-registration-form.png").default} alt="Account verification email notification" width="300" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/organization/self-service/customer/self-registration-form.png").default} alt="Account verification email notification" width="300" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

    :::note
    - Administrators can change which attributes users need to enter during the sign up process. Learn how to [update user attributes](../../users/attributes/user-attributes/manage-attributes.mdx) so that they are displayed in the user profile.

    <Edition only="cloud">

    - Users can either be allowed to use the email as the username or be asked to enter a separate username. Learn how to [configure username requirements](../../user-accounts/account-login/username-validation.mdx).

    </Edition>

    :::

3. Click **Sign Up** to create the account.

4. If **Account Verification** enabled, the user can confirm the account from the email.

    <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/organization/self-service/customer/account-verification-email.png").default} alt="Account verification email notification" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/organization/self-service/customer/account-verification-email.png").default} alt="Account verification email notification" width="500" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>

5. If **Account Verification** enabled, users can resend the account verification email if needed.
    - If **Activate Account Immediately** enabled, after successfully logging into My Account, a warning message with a resend link will appear. Click this link to resend the account verification email.

        <img src={require("../../../../assets/img/guides/organization/self-service/customer/resend-account-verification-email-immediate-account-activation-enabled.png").default} alt="Immediate Activation Enabled Warning" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

    - If **Activate Account Immediately** disabled, attempting to log in to **My Account**, will display a warning message indicating the account lacks activation, along with a resend link. Click this link to resend the account verification email.

        <Variants><Edition only="cloud"><img src={require("../../../../assets/cloud/img/guides/organization/self-service/customer/resend-account-verification-email-immediate-account-activation-disabled.png").default} alt="Immediate Activation Disabled Warning" width="400" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition><Edition only="self-hosted"><img src={require("../../../../assets/self-hosted/img/guides/organization/self-service/customer/resend-account-verification-email-immediate-account-activation-disabled.png").default} alt="Immediate Activation Disabled Warning" width="400" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} /></Edition></Variants>
