Welcome to the Quickstart Guide for <b>LoginFlow AI</b>! In this guide, you’ll learn how to use {edition.productName} LoginFlow AI to generate login flows for your applications, including passwordless login, Multi-Factor Authentication (MFA), social logins, and adaptive authentication logic that’s automatically generated.

## Configure Connections in {edition.productName}

MFA, passwordless and social providers are configured in {edition.productName} as **connections**. To start, set up the following **connections** in the {edition.productName} console. 

- To configure **username and password** login, no additional steps are required. {edition.productName} is pre-configured to use **username and password** as the default login option for your application. 

- {edition.productName} pre-configured with **Magic Link** and **Email OTP** as connections, so you can follow this guide without needing to modify the default settings. 

- Configure **GitHub** as a **social login provider** by creating a connection in {edition.productName} console.  
    1. Register a GitHub OAuth App or a GitHub App by following the [***Register WSO2 Identity Platform on GitHub*** step in this guide](../../../guides/authentication/add-federated-login/social-login/add-github-login.mdx#register-wso2-identity-platform-on-github). Once the GitHub app is registered you need to copy **`Client ID`** and **`Client secret`** for the next step. 

    2. Register GitHub connection in  {edition.productName} console by following the [***Register the GitHub IdP*** step in this guide](../../../guides/authentication/add-federated-login/social-login/add-github-login.mdx#register-the-github-idp). 

## Create and configure a sample app

You can either use the WSO2 Identity Platform [Try-It](../../try-it-application.mdx) hosted app without setting up a local app or create & run a sample app locally using the WSO2 Identity Platform React template. 

<Tabs groupId="tabs">
<TabItem value="using-wso2-identity-platform-try-it-hosted-app" label="Using WSO2 Identity Platform Try-It hosted app">

1. On the  {edition.productName} Console, go to **Home** and click **Try login with the Try It app**.
2. A dialog box appears prompting you to create a user account. Create a user account or if you already have one, click Continue to proceed.

:::note
{edition.productName} provides a hosted sample app called [Try-It](../../try-it-application.mdx) , which allows you to explore features like passwordless login, Multi-Factor Authentication (MFA), social logins, adaptive authentication, and user provisioning without the need to create or run a local app. Once you enable the {edition.productName} Try-It app, it will automatically register and configure an application in the {edition.productName} console, making it ready for you to use.
:::

</TabItem>
<TabItem value="using-wso2-identity-platform-react-template" label="Using  WSO2 Identity Platform React template ">

- Sign into WSO2 Identity Platform console and navigate to **Applications > New Application**.

- Select **Single Page Application** and complete the wizard popup by providing a suitable name and an authorized redirect URL.

:::note[Example]
**name:** asgardeo-react

**Authorized redirect URL:** http://localhost:5173
:::

-  Note down the following values from the Protocol tab of the registered application. You will need them to configure WSO2 Identity Platform React SDK.
    - **`client-id`** from the **Protocol** tab.
    - The **name** of your WSO2 Identity Platform organization

- Use the WSO2 Identity Platform React template to bootstrap your application by running the following command.  

  ```bash

  npx tmplr --dir my-vite-react-app asgardeo/asgardeo-vite-react-template
  ```
  The WSO2 Identity Platform React template generates a ready-made React sample app with pre-configured login and logout capabilities, helping you kick-start your project in just 2 minutes. 

</TabItem>

## Open the  **Login Flow AI** prompt {#open-the-login-flow-ai-prompt}

1.  On the {edition.productName} Console, go to **Applications**, and select the **Try It** application *(or select WSO2 Identity Platform-react app in case if you have created and running an app locally in the previous step)*.

2.  Go to the **Login Flow** tab of the application and click the **Try Login Flow AI** button to open the Login Flow AI prompt. 

<img src={require("../../../../assets/cloud/img/quick-starts/login-and-branding-ai/image1.png").default} alt="Login Flow" width="800" style={{display: "block", margin: "0"}} />

## **Try out Login Flow AI** - Password or MagicLink {#try-out-login-flow-ai-password-or-magiclink}

Enter the following given natural language instruction and click the run button. 

```text

Password or MagicLink 
```

The following login flow with username & password and Magic Link should be generated in the Login Flow designer. 

<img src={require("../../../../assets/cloud/img/quick-starts/login-and-branding-ai/image2.png").default} alt="username & password and Magic Link" width="800" style={{display: "block", margin: "0"}} />

Click the **Update** button to save the above login flow configuration. 

Next, click **Try Login** button in the top right corner of your screen. This will open the Try-It application in a new tab. 

Now you can try logging to the **Try It** application using either username & password or Magic Link.   

<img src={require("../../../../assets/cloud/img/quick-starts/login-and-branding-ai/image3.png").default} alt="username & password and Magic Link login" width="800" style={{display: "block", margin: "0"}} />

:::tip
You need to create a test user in {edition.productName} by following this [guide](../../../guides/users/users/manage-users.mdx) to tryout login and logout features. Also, make sure you have entered a valid email address in the user profile of the test user to the receive Magic Link login code. 
:::
