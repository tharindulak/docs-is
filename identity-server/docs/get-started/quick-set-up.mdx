Follow the steps given below to quickly set up and install {edition.productName} on your computer.

:::info
For detailed instructions on other installation options and deployments, see the [installation guide](../deploy-and-operate/get-started/install.mdx).
:::

## Install the {edition.productName}

Follow the steps given below.

1. Download and install Java SE Development Kit (JDK) version 21 or 25.
2. Go to [{edition.productName} official website](https://wso2.com/identity-server/) and click on **Download**.
3. Install {edition.productName} by downloading the **LATEST RELEASE**.

    :::info
    The installation location of {edition.productName} is referred to as `<IS_HOME>`.
    :::

{/* The WSO2 Identity Server installation location can vary depending on the operating system as given below:

|OS     |Home Directory                                |
|:------|:---------------------------------------------|
|macOS | `/Library/WSO2/IdentityServer/<IS_HOME>`         |
|Windows| `C:\Program Files\WSO2\IdentityServer\<IS_HOME>` |
|Ubuntu | `/usr/lib/wso2/IdentityServer/<IS_HOME>`         |
|CentOS | `/usr/lib64/IdentityServer/<IS_HOME>`           |

*/}

## Start the {edition.productName}

To start {edition.productName}, open a terminal, navigate to the `<IS_HOME>/bin` folder, and execute one of the following commands:

- On Linux/macOS

    ```bash
    sh wso2server.sh
    ```

- On Windows

    ```bash
    wso2server.bat
    ```

Note that the following log appears in the command prompt when the server starts:

![QSG start server](../../assets/self-hosted/img/get-started/qsg-start-server.png)

:::tip[Shutting down the server]
To shut down the server, press `Ctrl + C`.
Note that the following log appears in the command prompt on server shutdown.

![QSG stop server](../../assets/self-hosted/img/get-started/qsg-stop-server.png)
:::

## Access the Console

Once the server has started, you can access the {edition.productName} console by navigating to the following URL.

`https://{Server Host}:{Port}/console`

For example, if you are using default settings, the console URL will be `https://localhost:9443/console`.

You will then be presented with the login screen for the {edition.productName}. Enter `admin` for both username and password fields to login as the admin user.
