Changing default credentials before deploying the server in a production environment is crucial. Using default login information poses a significant security risk by making the system vulnerable to unauthorized access. This section provides guidance on enhancing the security of the {edition.productName} console by updating login details.

## Change the super admin password

To change the default admin password, log in to the {edition.productName} MyAccount portal with admin credentials and [change the password](../../guides/user-self-service/self-service-portal/change-password.mdx)

## Recover a password

If you forget your password, you can recover it using the [password recovery](../../guides/your-is/recover-password.mdx) option available on the {edition.productName}.

## Log in with an email address

You can configure the {edition.productName} to authenticate users using an email address instead of a username. Refer to [Enable Using Email Address as the Username](../../guides/users/attributes/enable-email-as-username.mdx) for further information.
