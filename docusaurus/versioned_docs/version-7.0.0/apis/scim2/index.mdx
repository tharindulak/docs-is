# SCIM 2.0 API

The SCIM2 Rest APIs of WSO2 Identity Server implements the SCIM 2.0 protocol according to the [specification](https://datatracker.ietf.org/doc/html/rfc7644). This section includes the following APIs.

- [SCIM 2.0 Users API](scim2-users-rest-api.mdx)
- [SCIM 2.0 Groups API](scim2-groups-rest-api.mdx)
- [SCIM 2.0 Patch operations](scim2-patch-operations.mdx)
- [SCIM 2.0 Bulk API](scim2-bulk-rest-api.mdx)
- [SCIM 2.0 Batch operations](scim2-batch-operations.mdx)
- [SCIM 2.0 Resource types API](scim2-resource-types.mdx)
- [SCIM 2.0 Service provider configuration API](scim2-sp-config-rest-api.mdx)

Additionally, learn how to [build SCIM 2.0 user creation payloads](build-scim2-user-creation-payload.mdx).
