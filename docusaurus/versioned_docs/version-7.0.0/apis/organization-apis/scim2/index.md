# User management

The SCIM2 Rest APIs of WSO2 Identity Server implements the SCIM 2.0 protocol for organizations according to the [specification](https://datatracker.ietf.org/doc/html/rfc7644). This section provides information on the following APIs.

- [SCIM2 organization users API](scim2-org-user-mgt.md)
- [SCIM2 organization groups API](scim2-org-group-mgt.md)
- [SCIM2 organization bulk API](scim2-org-bulk-mgt.md)
