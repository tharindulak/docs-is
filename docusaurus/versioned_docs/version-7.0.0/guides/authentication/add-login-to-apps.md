# Add login to Apps

This section gives you instructions for adding login to your Single Page Applications(SPAs) and web applications using OIDC or SAML.

- Secure your SPA with OpenID Connect using our SDKs or try it on a sample. See [Add login to an SPA](add-login-to-single-page-app.md).

- Secure your web application using OpenID Connect or SAML using our SDKs or try it on a sample. For more instructions, see [Add login to a webapp](add-login-to-web-app.md).

- Secure your mobile application with WSO2 Identity Server using OIDC. For more instructions, see [Add login to a mobile app](add-login-to-mobile-app.md).
