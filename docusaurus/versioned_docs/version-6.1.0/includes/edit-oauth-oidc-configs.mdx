1. Navigate to **Main** > **Identity** > **Service Providers** > **List**.

2. Click **Edit** to edit the OIDC service provider you created.

3. Expand **Inbound Authentication Configuration** > **OAuth/OpenID Connect Configuration**. 

4. Click **Edit**.
