# Organization APIs

This is the REST API documentation for APIs that are consumed by the B2B SaaS applications for organization-level operations.

## APIs in WSO2 Identity Server

WSO2 Identity Server exposes a set of APIs, allowing you to manage various organization settings and application settings programmatically. This is an alternative to using the WSO2 Identity Server Console.

Some of these APIs are used for organization management purposes, and they have special [authentication](#authentication) requirements. The management APIs of organization in WSO2 Identity Server are as follows:

- [Organization user management API (SCIM2)](org-user-mgt.mdx)

- [Organization group management API (SCIM2)](org-group-mgt.mdx)

- [Organization roles management API (SCIM2)](org-role-mgt.mdx)

- [Organization application management API](/identity/7.2.0/apis/organization-apis/org-application-mgt/)

- [Organization identity provider management API](org-idp-mgt.mdx)

- [Organization level organization management API](org-organization-mgt.mdx)

## Authentication

You need an access token to invoke APIs in organizations of WSO2 Identity Server. You can generate the required access tokens if you are an administrator or developer with access to the WSO2 Identity Server Console.

:::note

Learn how to [get access tokens for organization APIs](authentication.mdx).

:::
