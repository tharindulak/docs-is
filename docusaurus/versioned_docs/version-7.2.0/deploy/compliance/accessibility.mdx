# Accessibility compliance

WSO2 Identity Server conforms with Level A and Level AA success criteria and techniques of the Web Content Accessibility Guidelines 2.1 (WCAG 2.1).

This makes content on WSO2 Identity Server more accessible to a broader range of people with disabilities and makes the product more usable in general. With this, the business user registration interfaces and sign-in interfaces offered by WSO2 Identity Server are now operable through a keyboard interface. Color is not used as the only visual means of conveying information anymore.

Content is now robust and understandable, making it more user-friendly.

WSO2 provides a [Voluntary Product Accessibility Template (VPAT)](../../../../assets/_versions/7.2.0/vpat.pdf) document for WSO2 Identity Server with details of the product's compliance with Web Content Accessibility Guidelines 2.1 (WCAG 2.1).
