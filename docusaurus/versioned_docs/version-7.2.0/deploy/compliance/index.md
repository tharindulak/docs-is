# Compliance

Being compliant with industry regulations and law is a vital responsibility for any organization. WSO2 Identity Server is designed based on privacy best practices and is compliant with the following regulations.

- [GDPR](gdpr.md)

- [eIDAS](/identity/7.2.0/deploy/compliance/eidas)

- [CCPA](ccpa.md)

- [FIPS](fips.md)

- [FAPI](fapi.md)

- [Accessibility Compliance](accessibility.md)
