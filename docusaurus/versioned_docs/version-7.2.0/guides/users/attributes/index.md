# Manage attributes and mappings

Information directly related to users in an organization, such as username, email, address, etc., is stored as user attributes in WSO2 Identity Server. You can view the attributes, update them, and decide if and how they should appear in a user's profile. Learn more about [managing attributes in your organization](/identity/7.2.0/guides/users/attributes/manage-attributes/).

You can also map your [OpenID Connect attributes](manage-oidc-attribute-mappings.md) or [SCIM2 attributes](manage-scim2-attribute-mappings.md) to user attributes in your organization.
