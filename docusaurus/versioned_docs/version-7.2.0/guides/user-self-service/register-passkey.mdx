# Enroll passkeys

Application users can use the My Account portal to enroll their passkeys for [passwordless login](../authentication/passwordless-login/add-passwordless-login-with-passkey.mdx).


1. In the user's My Account portal, go to **Security** > **Additional Authentication**.

    ![Enroll passkey via MyAccount](../../../../assets/_versions/7.2.0/img/guides/passwordless/passkey/register-security-key-via-myaccount.png)

2. Click the **+** icon next to **Passkey** and follow the instructions given by the browser.

3. Once it's done, you will get the following prompt.

    ![Rename passkey via MyAccount](../../../../assets/_versions/7.2.0/img/guides/passwordless/passkey/rename-security-key-via-myaccount.png)

4. Provide a name for your device and click **Save**.
