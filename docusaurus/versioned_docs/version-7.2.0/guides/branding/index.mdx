# Branding

By default, your organization's business applications in WSO2 Identity Server are displayed to users with WSO2 Identity Server branding. However, you have the option to customize this by applying your own branding.

- [Customize the user interfaces (UIs)](configure-ui-branding.mdx) of the user login, sign-up, and account recovery flows.



- [Customize layouts](add-custom-layouts.mdx) of the user login, sign-up, and account recovery flows.





- [Use the editor to customize layouts](customize-layouts-with-editor.mdx) for user login, sign-up, and account recovery flows. 





- [Customize email notifications](customize-email-templates.mdx)

- [Localizations](localization.mdx)
