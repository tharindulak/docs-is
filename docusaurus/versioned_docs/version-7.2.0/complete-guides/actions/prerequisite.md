## Before you begin, ensure you have the following prerequisites

These prerequisites will help you to successfully complete the hands-on exercises and deployment steps in this guide:

* Approximately 120 minutes to complete all the examples and deployments.
* [Node.js](https://nodejs.org/en/download/package-manager) v22.0+ and npm installed on your machine.
* An active WSO2 Identity Server account to configure and test your service extensions.
* A [GitHub account](https://github.com/)
  and [Git CLI](https://git-scm.com/book/en/v2/Getting-Started-The-Command-Line) to manage and deploy
  your code repositories.
* A favorite text editor or IDE (such as Visual Studio Code, WebStorm, or any editor you are comfortable with).
* An [AbuseIPDB account](https://www.abuseipdb.com/register?plan=free) with an API key is required to
  check for abusive IP addresses in real time.

You will also need the following accounts to deploy and test the sample services:

* An active [Choreo account](https://choreo.dev/) for deploying sample services.
* A [Vercel account](https://vercel.com/signup) for cloud-hosting sample services.
* An [AWS account](https://signin.aws.amazon.com/signup?request_type=register) with console access to
  deploy and manage AWS Lambda functions.

Make sure all the accounts and tools are set up beforehand to ensure a smooth learning experience.
