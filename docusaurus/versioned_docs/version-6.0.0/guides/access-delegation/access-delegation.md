# Access Delegation - Overview

With delegated access control mechanisms, the owner of a set of resources can delegate access to some of those resources 
to a designated client application, without enabling the client application to impersonate the user. The following 
topics discuss the various features that are key to delegated access control.

-   [Authorization Code Grant](auth-code-playground.md) 

-   [Implicit Grant](implicit-playground.md)

-   [Client Credentials Grant](client-credentials-playground.md)

-   [Password Grant](password-playground.md)

-   [Microprofile JWT](microprofile-jwt-sample.md)

-   [SAML2 Bearer Assertion Profile](saml2-bearer-assertion-profile.md)

-   [Encrypt ID Tokens](oidc-token-encryption-sample.md)
