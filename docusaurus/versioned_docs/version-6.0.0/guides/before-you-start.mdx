# Guides - Overview

The guides in this section provide the instructions for building customer identity and access management use cases and managing them.

## Login and access control

When you use WSO2 Identity Server as the identity provider for your applications, you can enforce strong, flexible authentication and control access to resources.

- [Authentication](authentication-overview.mdx)
- [Identity Federation](identity-federation/identity-federation-overview.mdx)

- [Access Control](authorization/overview.mdx)
- [Access Delegation](access-delegation/access-delegation.mdx)

## User identities and tenants

Onboard users and manage their identities in WSO2 Identity Server to facilitate your application login and access to resources.

- [Users](identity-lifecycles/user-management.mdx)
- [Claims](dialects/dialects-overview.mdx)
- [Consent](consent-mgt/manage-user-consent.mdx)
- [Tenants](tenants/tenant-mgt.mdx)

## User self-service

Allow your users to manage their user accounts and profiles from the self-service portal. [Learn more](my-account/my-account.mdx).

## Analytics

You can configure the WSO2 Identity Server to publish authentication and session related events to the ELK cluster and use Kibana dashboards to view analytics. [Learn more](elk-analytics/elk-analytics.mdx).
