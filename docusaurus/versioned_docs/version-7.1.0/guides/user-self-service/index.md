# User self-service

WSO2 Identity Server provides a built-in self-service portal which users can use to manage their own accounts. Learn more about the [My Account portal](overview.md) and its capabilities.

You can also incorporate self-service capabilities into your business applications by invoking the APIs offered by WSO2 Identity Server. Refer [Build self-service capabilities](build-self-service-capabilities.md) to learn more.
