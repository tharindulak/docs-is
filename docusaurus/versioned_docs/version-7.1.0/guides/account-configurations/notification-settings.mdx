# Notification settings

WSO2 Identity Server, by default, provides a seamless notification system that handles notifications for the following scenarios.

- Self registration
- Email verification
- Account lock
- Account disable
- Account recovery

If the client application handles notifications and you want to disable the notification features of WSO2 Identity Server,

1. On the WSO2 Identity Server Console, go to **Login & Registration**.

2. Under **Notification Settings**, click **Internal Notification Sending**.

3. Turn the toggle off to disable notifications.
