# SCIM 2.0 API

The SCIM2 Rest APIs of WSO2 Identity Platform implements the SCIM 2.0 protocol according to the [specification](https://datatracker.ietf.org/doc/html/rfc7644). This section provides information on the following APIs.

- [SCIM2 Users API](scim2-users-rest-api.mdx)
- [SCIM2 Groups API](scim2-groups-rest-api.mdx)
- [SCIM2 Bulk API](scim2-bulk-rest-api.mdx)
- [SCIM2 Batch Operations](scim2-batch-operations.mdx)
- [SCIM2 Resource Types API](scim2-resource-types-rest-api.mdx)
- [SCIM2 Service Provider Configs API](scim2-service-provider-configs-rest-api.mdx)
- [SCIM2 Build User Creation Payload](build-scim2-user-creation-payload.mdx)

</Applies>
