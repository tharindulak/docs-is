# Organizations

If you are a Business-to-Business (B2B) service provider, you may use WSO2 Identity Platform's organizations to represent your partners/suppliers. You may then share your applications with organizations that should have access to them. Moreover, you may delegate administration of organizations to admins within the organizations so that they can start managing access to the shared applications.

- Partners/Suppliers of your business must be set up as organizations in your organization.

    :::note

    See [Manage organizations](manage-organizations.mdx) for instructions.

    :::

- Create an administration portal or use the organization Console to manage organizations.

    :::note

    See [Administration of organizations](manage-b2b-administration.mdx) for instructions.

    :::

- Share applications with organizations that should have access to them. When an application is shared, organization users can log into them. Any roles associated with the application will also be shared with the organization. Organization admins can leverage these roles to control access to the applications.

    :::note

    See [Share applications](share-applications.mdx) for instructions.

    :::

- Onboard administrators to the organizations.

    :::note

    See [Onboard organization admins](onboard-org-admins/index.mdx) for instructions.

    :::


- Try out a complete B2B use case.

    :::note

    See  [Try a B2B use case](try-a-b2b-use-case.mdx) for instructions.

    :::
