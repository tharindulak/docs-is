<Applies to="WSO2 Cloud">

## Before you start, ensure you have the following

* About 60 minutes
* WSO2 Identity Platform account
* Create [a test user in WSO2 Identity Platform](../../guides/users/manage-users.md#onboard-users)
* [Node.js](https://nodejs.org/en/download/package-manager) v20+ and npm
* Access to the [Google Developer Console](https://console.developers.google.com/apis/credentials)
* A favorite text editor or IDE




:::note[Note]


You need to have installed [Node.js](https://nodejs.org/en/download/package-manager) v18.8+ and npm (which comes inbuilt with Node) to run this sample. Although Node.js is primarily a server-side language,it needs to have been installed to manage dependencies and run scripts for our project.

:::

</Applies>
