<Applies to="WSO2 Cloud">

Before you start, ensure you have the following:

- About 60 minutes of time.
- A WSO2 Identity Platform account.
- Create [a test user in WSO2 Identity Platform](../../guides/users/manage-users.mdx#onboard-users)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) or later.
- [Visual Studio Code](https://code.visualstudio.com/).

</Applies>



<Applies to="Self-hosted">

Before you start, ensure you have the following:

- About 60 minutes of time.
- Create [a test user in Identity Server](https://is.docs.wso2.com/en/7.1.0/guides/users/manage-users/#onboard-users)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) or later.
- [Visual Studio Code](https://code.visualstudio.com/).

</Applies>
